# 归一 · Guiyi Labs

> 让复杂系统归一：可观测、可诊断、可控制。

专注 Kubernetes、DevOps、AIOps 与自动化工程实践，持续构建可运行、可验证、
可交付的运维平台和技术资料。

## 关注方向

- Kubernetes 多集群管理、可观测性与故障诊断
- 确定性规则优先、AI 增强解释的 AIOps 系统
- 网络自动化巡检、故障定位与报告闭环
- DevOps 任务编排、受控变更与工程质量门禁
- 可信 RAG、知识图谱与垂直领域科研平台

## 工程原则

- 先建立确定、可复现的主链路，再引入 AI 增强能力。
- 所有高风险操作都应经过权限校验、预览、确认、幂等和审计。
- 用自动化测试、真实环境验证和归档证据支撑交付结论。
- 保持能力边界明确，避免把平台演变成任意权限代理。

当前重点：Kubernetes 多集群 AIOps 平台、真实集群验证与版本化交付。
